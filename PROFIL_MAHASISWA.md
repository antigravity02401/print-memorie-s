## Panduan untuk AI (Antigravity)

Ketika pengguna mengajukan pertanyaan atau soal terkait tugas/pembelajaran,
cari dan ambil data terlebih dahulu dari folder berikut sesuai mata kuliah:

- Penetration Testing   -> tugas/Penetration Testing/
- Metodologi Penelitian -> tugas/Metodologi Penelitian/
- Manajemen Proyek      -> tugas/Manajemen Proyek/

Catatan: File tugas yang sudah ada di root folder tugas/ bisa dipindahkan
ke folder mata kuliah yang sesuai jika diperlukan.
