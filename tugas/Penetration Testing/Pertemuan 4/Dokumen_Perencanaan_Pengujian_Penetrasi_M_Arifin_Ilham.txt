5. EXPLOITATION
================================================================

Kategori Kerentanan      | Teknik / Payload Contoh                     | Tools
-------------------------|---------------------------------------------|-------------------
SQL Injection            | UNION-based / boolean-based blind pada       | sqlmap,
                         | parameter id atau search                     | Burp Repeater
Cross-Site Scripting     | Reflected XSS via parameter pencarian,       | Burp Suite,
(XSS)                    | <script>alert(document.cookie)</script>      | payload manual
Broken Authentication    | Uji kredensial umum form login secara        | Burp Intruder
                         | terbatas (rate-limited, bukan brute force)   | (terbatas)
Broken Access Control    | Manipulasi parameter id (user_id, booking_id)| Burp Repeater,
/ IDOR                   | untuk akses data akun lain                   | param tampering
Session Management       | Uji token sesi setelah logout;               | Burp Suite
                         | apakah token dapat ditebak/diprediksi        | (cookie inspect)
Business Logic           | Manipulasi nilai harga/kuantitas booking     | Burp Repeater,
                         | (mis. kuantitas negatif) untuk uji validasi  | manual

Tools eksploitasi yang dipakai:
  [v] sqlmap (validasi & eksploitasi SQL Injection)
  [v] Burp Suite Intruder/Repeater (payload manual & terautomasi)
  [v] OWASP ZAP (manual attack mode)
  [v] Payload/skrip kustom (XSS payload, IDOR parameter tampering)

Tools yang TIDAK dipakai (batasan RoE):
  Metasploit modul jaringan/OS, exploit biner/binary payload, dan semua
  tools yang menyasar lapisan OS/server.

Kriteria temuan tervalidasi:
  Berhasil mengeksekusi payload dan mengonfirmasi dampaknya secara nyata
  (data terekspos, sesi terbajak, atau akses tidak terotorisasi terbukti).

Kriteria BERHENTI (wajib, tidak dapat diubah):
  Begitu command injection atau kerentanan lain terbukti memberi akses
  tingkat OS/server, aktivitas DIHENTIKAN dan segera dilaporkan sesuai
  prosedur eskalasi RoE -- tidak dieksplorasi lebih lanjut.

================================================================
6. POST-EXPLOITATION
================================================================

Penilaian dampak dilakukan melalui analisis, bukan dengan aktivitas
lanjutan yang melampaui exclusion list RoE (tanpa lateral movement).

Jenis data yang berpotensi terekspos:
  - Data pribadi pengguna (nama, alamat, nomor telepon, email)
  - Data kredensial (username/password hash)
  - Data transaksi/booking kos
  - Informasi internal aplikasi (struktur database, path server)

Dampak bisnis jika dieksploitasi pihak luar:
  - Kebocoran data pengguna --> pelanggaran privasi dan kepercayaan
  - Manipulasi data booking --> kerugian finansial dan operasional
  - Eskalasi akses admin --> kendali penuh atas sistem
  - Downtime aplikasi --> gangguan layanan mitra
